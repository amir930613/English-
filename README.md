# 🌍 LinguaLand — Тренажёр английского языка

Современное PWA-приложение для изучения английского языка с использованием интервального повторения (SRS), викторин, практики перевода и экзаменов по уровням CEFR (A0-C2).

## 📁 Структура проекта

```
/workspace
├── index.html              # Главный HTML файл (минимальный)
├── manifest.webmanifest    # PWA манифест
├── sw.js                   # Service Worker
├── icon.svg                # Иконка приложения
├── README.md               # Документация
└── src/
    ├── css/
    │   ├── variables.css   # CSS переменные и темы
    │   ├── components.css  # Стили компонентов UI
    │   └── views.css       # Стили экранов
    ├── js/
    │   ├── config.js       # Конфигурация приложения
    │   ├── utils.js        # Утилиты (XSS защита, localStorage)
    │   ├── state.js        # Управление состоянием (State Manager)
    │   ├── app.js          # Главный модуль приложения
    │   ├── index.js        # Экспорт всех модулей
    │   └── modules/
    │       ├── profiles.js     # Управление профилями
    │       ├── cards.js        # Карточки и SRS
    │       ├── quiz.js         # Викторины
    │       ├── exam.js         # Экзамены
    │       ├── practice.js     # Практика перевода
    │       ├── achievements.js # Достижения
    │       └── ui.js           # UI утилиты
    └── data/
        └── words.js        # Слова по уровням CEFR
```

## ✨ Возможности

### 🔐 Профили пользователей
- Мультипрофильность с хранением в localStorage
- Экспорт/импорт профилей (JSON + CSV)
- Миграция данных между версиями

### 📚 Карточки с SRS
- Интервальное повторение для запоминания
- Аудио произношение (SpeechSynthesis API)
- Свайпы для мобильных устройств
- Горячие клавиши (Пробел, Стрелки)

### 🎯 Викторины
- Генерация вопросов по уровням
- Мгновенная обратная связь
- Статистика результатов

### 📝 Экзамены
- Таймер времени
- Вопросы всех уровней A0-C2
- Порог прохождения 70%
- Сертификаты о прохождении

### 💪 Практика перевода
- Перевод предложений
- Анализ ошибок
- Повторение сложных моментов

### 🏆 Достижения
- 15+ достижений для мотивации
- Отслеживание прогресса
- Серия дней подряд (streak)

### 🎨 UI/UX
- Тёмная и светлая тема
- Адаптивный дизайн
- Toast уведомления
- PWA установка на устройства

## 🚀 Установка и запуск

### Локальный запуск
```bash
# Клонируйте репозиторий
cd /workspace

# Запустите локальный сервер
python -m http.server 8000

# Откройте в браузере
http://localhost:8000
```

### PWA установка
1. Откройте приложение в Chrome/Safari
2. Нажмите "Установить приложение" или "Добавить на главный экран"
3. Приложение будет работать офлайн

## 🛠 Технологии

- **Vanilla JavaScript (ES6 Modules)** - без фреймворков
- **CSS Variables** - темизация и адаптивность
- **localStorage** - хранение данных
- **Service Worker** - offline поддержка
- **SpeechSynthesis API** - аудио произношение

## 📊 Архитектура

### Модульная структура
```
App (главный класс)
├── UIManager (UI и уведомления)
├── ProfileManager (профили пользователей)
├── CardManager (карточки и SRS)
├── QuizManager (викторины)
├── ExamManager (экзамены)
├── PracticeManager (практика)
├── AchievementManager (достижения)
└── State (единое состояние приложения)
```

### Управление состоянием
Все данные хранятся в централизованном хранилище `state` с поддержкой:
- Подписки на изменения
- Глубокого клонирования
- Очистки ресурсов

## 🔒 Безопасность

- **XSS защита**: функция `esc()` для экранирования ввода
- **CSP**: Content Security Policy мета-тег
- **Безопасный localStorage**: обработка ошибок переполнения
- **Проверка API**: наличие SpeechSynthesis перед использованием
